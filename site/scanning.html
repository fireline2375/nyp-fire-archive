Ingest pipeline · stage three

Catching sensitive material before a human has to

Thousands of pages will pass through this project. Expecting a reviewer to spot every Social Security number on a 1970s form, or every patient name buried in an incident packet, is how things get missed. An automated pass reads every page on ingest and flags what looks sensitive, so the reviewer's queue arrives pre-sorted and the obvious cases never reach a public URL by accident.

The rule that makes this safe

The automated pass can only ever move an item toward being restricted. It can flag, it can propose a redaction, it can escalate to withheld. It cannot approve anything, clear anything, or remove a flag a human has set. A model that could mark records safe for release would be a liability; one that can only raise its hand is a net.

    Where the pages actually go

    This is the question a records coordinator will ask, and it deserves a straight answer: to detect PHI in a document, something has to read the document. So where does that reading happen?

    Pass Runs where Catches
    Pattern pass On my machine. Nothing leaves it. Social Security numbers, dates of birth, phone numbers, addresses, driver's licence and plate formats, medical vocabulary, form types
    Local model pass
    open weights, on-device    		 On my machine. Nothing leaves it. Person and place names, the difference between a crew roster and a discipline file, medical narrative in prose
    Hosted model pass
    e.g. Claude · off by default    		 In the vendor's data centre — a hosted assistant cannot be installed locally, so pages are sent over the internet. Only with the Unit's written approval, and only on pages the local passes cleared Description, subject indexing, difficult handwriting, and the contextual judgement local tooling is worst at — enrichment, not screening

    The screening passes are local by design, because sending a page to a third party in order to find out whether it contains PHI means the PHI has already left the building. A hosted model such as Claude is a separate decision and the Unit’s to make — it is genuinely better at the contextual judgement listed under “what it is bad at” below, but it cannot run on a laptop, so using it means document text leaves the building. The protections for that are real and obtainable — no training on API content, default deletion inside thirty days, zero-retention agreements, and HIPAA-ready access under a signed business associate agreement where PHI is involved — but they have to be in writing, not assumed. My recommendation is to run the pilot entirely locally and revisit this once there is something concrete to judge.

    What it is bad at

    Stating this plainly matters more than the capability list, because the failure mode is a record going public that should not have:

    • Handwriting. OCR on a 1960s carbon copy in cursive is poor, and the pass can only flag what it can read. A name it cannot read is a name it cannot flag.
    • Context. A name on a promotion announcement is fine. The same name on a complaint file is not. The pass sees text, not the situation.
    • Photographs. A street number on a mailbox, a face, a plate in frame — these are not text and will not be caught by a text pass.
    • Confidence is not correctness. A high score means the pattern matched, not that the judgement was right.

    Which is why the default stays what it already was: unreviewed means private. The automated pass shortens the queue and catches the obvious; it does not reduce what needs a human. Nothing is published because a model said it was fine.

    What gets recorded

    Every flag is written with the rule or model that raised it, its version, the page and character range, a confidence score, and a timestamp. A reviewer can see why an item was flagged, and the Unit can spot-check whether the pass is any good.

    Measured, not asserted

    During the pilot I would hand-label a sample of pages and report how the pass actually performed — what it caught, and more importantly what it missed. A flagging tool with no measured miss rate is a comfort blanket.

    A human still reads everything

    Every item reaching the public has been looked at by a Unit reviewer. The pass changes the order of the queue and what is highlighted in it. It does not remove a step.
