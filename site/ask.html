Ask the archive a question

Keyword search finds documents. It does not answer questions. A retrieval agent reads the approved records, answers in a sentence, and cites the records it used so the answer can be checked. This is the one feature on this site that costs money per use, which is why it sits last and is marked optional.

Not built — this is a mock-up

The answers below are written out in advance, not generated. Nothing is connected to any model and no request leaves this page. The point is to show the shape of the feature, and in particular what it does when it cannot answer.

What it costs

A question means sending the retrieved record text to a model and getting a few hundred words back. At current list prices, per question:

Opus 5.5 $4.00 / $20.00 ~9¢ ~$47

Assumes roughly 20,000 input tokens of retrieved records and a short answer. Prompt caching on the fixed instructions brings the input side down further on repeat use. These are list prices and will change; treat them as an order of magnitude, not a quote.

So the honest version is: a few cents a question, with a hard monthly ceiling. At a $25 cap on the cheap model that is roughly a thousand questions a month. When the cap is reached the feature switches itself off and the box above says so — it does not quietly keep spending, and it does not degrade into guessing. Ordinary search carries on working, because ordinary search is free.

It searches as you, not as itself

The agent has no account of its own and no standing access. It runs every query under the permissions of whoever asked. A member of the public asking a question gets an agent that can read exactly the approved records they could have read themselves — the same row-level rules, no bypass.

Withheld stays invisible

This is the subtle part. When the answer lives in a withheld record, the agent does not say “there is a sealed document about that.” It says the catalog holds nothing on it, because from where it is standing that is true.

An agent that could report the existence of withheld material would leak the thing the gate exists to protect. Try the second question.

No citation, no claim

Every sentence of fact carries a record id a researcher can open and check. If the records do not support an answer, the required response is to say so. An archive whose search invents a date is worse than an archive with no search.

Read-only

It cannot approve, withhold, flag, redact, catalog or edit anything. It is a reader with a citation habit. The ingest pass and the review gate are untouched by it.

Last, not first

Everything else in this proposal works without it. This is the only part with a per-use bill, so it belongs after the archive exists and has proved useful — and it is the obvious thing to point a fundraiser at, because the cost is legible.
